# Assembly bind shell 
A simple bind shell written in assembly for x86-64 linux systems 

## Disclaimer 
This was developed solely for educational purposes. 
Do not run this program on production systems.

## How to assemble and run 
```console
$ make
$ ./bindshell
``` 

To connect to the shell you can use a tool like nc 
```console
$ nc <HOST> 4444
```
